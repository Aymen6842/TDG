Non-functional priorities
Security
Centralized RBAC · ~31 roles · ~120 permissions, one guard per route.
Data sovereignty
Self-hosted; internal data never leaves the organization.
Performance
Stateless API, indexed Postgres, asynchronous indexing.
Internationalization
Fully bilingual (en / fr) via next-intl.

Methodology

We chose Scrum to deliver a broad platform incrementally, validate each module with TDG, and adapt priorities as the project evolved.

Incremental delivery

Each sprint produced a working slice of the platform.

Continuous feedback

Reviews with TDG kept the solution close to operational needs.

Adaptive priorities

The AI sprint could build on the real work history delivered earlier.
